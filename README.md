## 🚦 Featured Project

### Token Bucket Rate Limiter

A high-performance backend rate-limiting service built with **Java and Spring Boot** using the **Token Bucket algorithm**.

#### Highlights

* 🚀 Enforces **100 requests per second (RPS) per client**
* 🪣 Implements the **Token Bucket algorithm** for traffic control
* 🧪 Validated using **Apache JMeter**
* ⚡ Sustained **100 RPS under load testing**
* 🛡️ Rejects requests exceeding configured limits using appropriate HTTP status codes
* 🔧 Designed to protect backend APIs from sudden traffic spikes

**Tech:** `Java` `Spring Boot` `Redis` `Token Bucket` `JMeter`
